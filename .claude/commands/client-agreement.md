# client-agreement

Record the day a client agreed in writing that a site may be staffed by a subcontractor (NSW s 38A(1)(a)).

Run `node scripts/guarding.mjs client-agreement <site> --date=YYYY-MM-DD [--note=] --actor="<name>"`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Only record an agreement the operator has in writing.
