# compliance

Check the roster and incidents against the rules in docs/compliance.md, law first, each with its source.

Run `node scripts/guarding.mjs compliance [--days=14] [--past=30]`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Table: rule, count, the first example, the source. Never present a house rule as law.
