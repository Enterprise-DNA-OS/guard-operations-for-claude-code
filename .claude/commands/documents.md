# documents

Run `npm run docs`, or `npm run docs -- invoice` for one kind (`client-service-report`, `incident-report`, `invoice`, `site-instructions`), or `npm run docs -- incident-report <id-prefix>` for one record. Files land in `docs-out/`. Change the business name, colours and logo in `brand.json`. Check each one before it goes out; nothing is sent.
