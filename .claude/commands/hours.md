# hours

Each site this week (Monday to Sunday, site time): contracted, rostered, open and worked hours, and the gap to contract.

Run `node scripts/guarding.mjs hours`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with sites short of contract.
