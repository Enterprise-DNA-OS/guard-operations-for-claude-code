# incidents

Every incident, newest first, with whether the client and regulator have been told. --open hides closed ones.

Run `node scripts/guarding.mjs incidents [--open]`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with regulator not notified, then client not told.
