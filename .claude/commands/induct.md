# induct

Record that an officer has been inducted at a site.

Run `node scripts/guarding.mjs induct <officer> <site> [--date=YYYY-MM-DD] [--by="<who>"] --actor="<name>"`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Confirm in one line.
