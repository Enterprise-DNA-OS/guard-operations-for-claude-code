# invoices

Every invoice with its standing: not sent, sent, overdue or paid.

Run `node scripts/guarding.mjs invoices`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with overdue.
