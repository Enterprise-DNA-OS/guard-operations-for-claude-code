# training

Record that an officer on a temporary certificate has finished the required training.

Run `node scripts/guarding.mjs training <officer> --date=YYYY-MM-DD --actor="<name>"`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Remind the operator to apply for the full certificate.
