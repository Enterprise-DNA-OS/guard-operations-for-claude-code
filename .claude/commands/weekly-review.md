# weekly-review

Write the Monday review to drafts/ from attention, compliance, open shifts, hours and unbilled work.

Run `node scripts/guarding.mjs weekly-review`. Add `--json` when you need every field. Resolve the site, officer, shift or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Summarise in five lines: what breaks the law, what is open, what lapses, what the client has not heard, what is unbilled.
